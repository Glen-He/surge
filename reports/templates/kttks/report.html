执行摘要

  • 模拟数据全部通过科学 QC。七个窗口的 40 ns production 均完整结束，最终纳入分析的轨迹为 7/7 GO；本报告讨论的“不稳定”专指扩散系数估计对积分终点敏感，并不代表 MD 运行失败。
  • 七个作者口径的 D1000 均已计算完成。z=0.31–2.81 nm 的六点位于 1.34×10⁻⁷–4.90×10⁻⁷ cm²/s；z=4.00 nm 的作者口径结果为 2.85×10⁻⁵ cm²/s，明显高于其余窗口。
  • 不同窗口的数值精度并不相同。z0.31 的 running integral 形成清晰平台，z2.81 仅呈弱平台；其余五个窗口在 500–1000 ps 内仍明显变化，因此 D1000 是统一方法口径下的主估计值，而不是全部已经收敛的精确常数。
  • z4.00 的高值必须谨慎解释。该窗口的相关积分接近零，D 又与积分成反比，因此 cutoff 和仅 0.2 ps 的抽样相位变化都会被显著放大；高数值可以保留为作者兼容输出，但不能据此断言真实扩散速度比膜内窗口高两个数量级。

KTTKS_2 单 profile 扩散系数 DA(z)

D(z) 给出物理结果，不能单独证明估计已经稳定

在 restrained simulation 中，KTTKS_2 被固定在指定膜深度，体系记录膜、水和脂质施加在肽上的约束力波动。作者脚本先计算去均值后的力自相关函数 CF(t)，再将其积分为累计摩擦 I，最后按下式换算 D：

D(τ) = 10−14(RT)2I(τ) ； I(τ) = ∫τ0 CF(t) dt

因此，D 小表示累计摩擦大、运动更受阻；D 大表示累计摩擦小、运动相对容易。但 D 是积分的倒数：当 I 已经很小、仍在变化时，D 会对计算细节非常敏感。所以 D 的高低是物理结果，估计是否稳定必须结合后面的 running integral 与 cutoff sensitivity 判断。

图中靛蓝线是作者兼容 extraction 的正式 D1000，琥珀线是把抽样起点校正 0.2 ps 后的独立验证。纵轴为对数尺度。z0.31–z2.81 六点跨越约 3.7 倍，仍处于同一 10⁻⁷ cm²/s 数量级；z4.00 比前六点中最高值约高 58 倍、比前六点中位数约高 135 倍。

前六窗两种 extraction 的 D1000 差异均不超过 2.23%，说明 0.2 ps 的抽样相位对这些窗口影响较小。z4.00 的相位差达到 20.70%，与其近零积分和无平台状态一致。因而曲线的主要结论不是“z4.00 已被精确证明扩散最快”，而是作者公式在该窗口产生了一个极高、同时高度敏感的点估计。

ACF 展示“力的记忆”，但最终判断要看其累计面积

ACF 比较当前的力波动与延迟 t 之后的力波动。CF(t)>0 表示两时刻的波动倾向同向，CF(t)<0 表示倾向反向回弹，接近零表示线性记忆已经很弱。七个窗口在短 lag 都从较强正相关快速衰减，说明约束力不是每个 1 ps 样本都完全独立，而是具有有限时间的连续记忆。

“ACF 看起来靠近零”还不等于 D 已经稳定。原因是 D 取决于从 lag=0 开始的全部曲线面积；尾部单个起伏虽小，但如果较长时间偏正或偏负，累加后仍会持续推高或压低 I。不同窗口的尾部起伏方向和累积结果不同，正是后续 D 随 cutoff 上升或下降的来源。

z0.31尾部正负贡献在 500–1000 ps 内基本抵消，累计面积趋稳。
z0.56 / z2.01 / z2.29尾部累计净贡献为正，积分继续增大，D 随 cutoff 降低。
z0.99尾部累计净贡献为负，积分继续减小，D 随 cutoff 升高。
z4.00长 lag 的累计抵消把总面积压到接近零，使倒数换算极不稳定。

Running integral 是本报告判断稳健性的核心证据

Running integral 是 ACF 从 0 到当前 lag 的累计面积，也是 D 公式中的分母。如果 ACF 的有效记忆已经结束，继续向后积分只会加入接近零的量，曲线就会形成平台；此时在合理范围内改变积分终点，得到的摩擦和 D 都基本不变。

图中阴影对应统一的 500–1000 cutoff 审计范围（在作者代码中实际最大 lag 为参数减 3 ps）。平台不是要求曲线等于零，而是要求曲线在一段足够长的区间内不再持续单向变化。平台高度可以很大或很小；只要高度稳定，D 的分母就不依赖人为选择的积分终点。

z0.31 的 I 从 1.56×10⁻⁷ 变为 1.48×10⁻⁷，仅小幅调整后趋平，对应 D 只变化 +5.48%，是唯一清晰平台。z2.81 的 I 从 2.02×10⁻⁷ 增至 2.47×10⁻⁷，后段斜率减弱但尚未完全稳定，因此判为弱平台。

z0.56、z2.01、z2.29 的 I 在阴影区持续上升，说明继续积分仍在累加同号净面积；z0.99 则持续下降，说明负的尾部贡献仍在抵消早期正面积。这四窗都没有出现足够清晰的平台。

z4.00 的 I 从 9.66×10⁻⁹ 降至 2.33×10⁻⁹，下降约 76%，最终值比前六窗 I 的中位数低约 146 倍。由于 D∝1/I，这个很小且仍在下降的分母把 D 放大到 10⁻⁵ cm²/s，同时也放大了 cutoff 与抽样相位带来的任何细微变化。

Cutoff sensitivity 把“平台是否足够平”转换成可量化结果

Cutoff 是 ACF 积分停止的位置。对每个窗口统一计算 500、600、700、800、900 和 1000 ps 六个终点；如果累计摩擦已经形成平台，六个 D 应当接近水平。这里的“平”只评价同一个窗口在不同 cutoff 下是否稳定，不要求 D 随膜深度 z 呈平滑或单调变化。

z0.31 从 D500 到 D1000 仅变化 +5.48%，平台最清晰。z2.81 变化 −18.34%，曲线后半段相对收窄，因此归为弱平台。z0.56、z0.99、z2.01、z2.29 的端点变化为 32.64%–54.06%，且方向与各自 running integral 的上升或下降完全相反，符合 D∝1/I。

z4.00 从 6.88×10⁻⁶ 增至 2.85×10⁻⁵ cm²/s，端点变化 +314.40%，中间还出现明显回落与再上升。这不是稳定平台周围的小幅噪声，而是积分分母接近零时倒数换算产生的强烈放大。

D1000 仍固定作为所有窗口的主列，因为这保持了作者脚本和统一分析协议；平台判定则单独描述这个主估计值的稳健程度。没有为任何窗口挑选更“好看”的 cutoff，也没有因 D 不平滑而改用其他时间段。

综合结论

1. 轨迹层结论

七个正式来源均已通过 production 科学 QC，因此全部可以进入既定的力自相关分析。此处不存在“七个 MD 大部分失败”的结论；平台不足发生在有限 10 ns 力序列对长时间相关积分的估计层。

2. 扩散系数层结论

z0.31 的 D1000=4.50×10⁻⁷ cm²/s 具有本批数据中最清晰的 cutoff 稳健性。z2.81 的 D1000=2.69×10⁻⁷ cm²/s 具有弱平台支持。z0.56、z0.99、z2.01 和 z2.29 的作者口径数值均可复现，但其 500–1000 ps running integral 尚未形成清晰平台，绝对值应视为 cutoff-sensitive 点估计。

3. z4.00 的解释边界

z4.00 的 D1000=2.85×10⁻⁵ cm²/s 是作者公式的真实输出，不是程序报错；但该值依赖一个接近零且仍在变化的积分分母。314.40% 的 cutoff 变化和 20.70% 的 extraction-phase 差异共同表明，其数量级不具备与 z0.31 相同的稳健性。

4. 报告范围

本报告给出的是 KTTKS_2 single-profile DA(z)。论文最终 KTTKS 曲线由两个独立 X–Y binding environment 的 profile 平均得到；当前没有第二条独立 profile，因此本结果不能命名为论文完整 Fig.5 的最终复现。

数据口径与计算方法

  • 模拟输入：7 个固定 z 窗口，每窗 40 ns restrained production；所有最终来源均为 QC GO。
  • 分析时间窗：固定使用 30–40 ns，不因结果形状更换时间段。
  • 作者兼容 extraction：受 XVG 物理行号相位影响，得到 10,000 点，时间为 30000.2–39999.2 ps，间隔 1 ps。
  • 相位校正验证：从数值数据首点开始抽样，得到 10,001 点，时间为 30000.0–40000.0 ps；仅用于敏感性校验，不替换主结果。
  • 主估计：原作者 `Compute_diffusivity.py`，temperature=310 K，cutoff argument=1000。由于作者循环实现，实际计算 998 个 lag，即 0–997 ps。
  • 统一敏感性审计：所有窗口同时计算 cutoff=500、600、700、800、900、1000，不逐窗选择终点。
